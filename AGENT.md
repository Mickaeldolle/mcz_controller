# Point d'entrée pour un agent de code

Commencer par **[AGENTS.md](AGENTS.md)**, le guide de référence de ce dépôt.
Il contient le contexte, les règles de modification, les limites matérielles et
les liens vers l'architecture, les commandes de validation et l'état du projet.

Ce fichier conserve le nom `AGENT.md` demandé. Les consignes sont centralisées
dans `AGENTS.md`, nom utilisé par de nombreux outils d'agents, pour éviter
deux versions divergentes. Si votre outil ne charge que ce fichier, lire
explicitement `AGENTS.md` avant toute intervention.
